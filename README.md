# Gmail 조직도 연동 Chrome Extension

이 확장 프로그램은 Gmail 작성 화면에 조직도 아이콘을 삽입하고, 클릭 시 조직도 웹 서버와 연동하여 사원의 이메일 주소를 자동으로 입력해주는 Chrome Extension입니다.

## 주요 기능

- Gmail 작성 화면에 조직도 아이콘 삽입
- 팝업 UI에서 사원 목록 확인 및 검색
- 사원 클릭 시 이메일 주소 자동 입력
- To / Cc / Bcc 칸에 대응

## 연동 서버

본 확장 프로그램은 조직도 프로그램과 연동되어 동작합니다.  
- 링크: https://github.com/jooho172200/new_orgtree

## 설치 방법

1. 이 레포지토리를 클론합니다.
2. Chrome `chrome://extensions/` 접속 → **개발자 모드 ON**
3. **"압축 해제된 확장 프로그램을 로드"** 클릭 후 프로젝트 디렉터리 선택
4. Gmail 작성 화면에서 조직도 아이콘 확인

## 제한 사항

- 조직도 서버가 로컬 혹은 사내 서버에 실행 중이어야 전체 기능이 정상 작동합니다.
- Gmail UI 구조 변경 시 일부 기능이 동작하지 않을 수 있습니다.
